מדריך הפעלה ושימוש

מה הכלי עושה?

הכלי אוסף אוטומטית את כל עסקאות הנדל"ן מתוצאות חיפוש שביצעת באתר רשות המיסים, עובר על כל העמודים, נכנס לכל עסקה, מחלץ את כל הפרטים ושומר את הכול לקובץ output.xlsx מסודר.

אתה מבצע את החיפוש בעצמך בדפדפן (התחברות, סינון וכו'), והכלי עושה את כל העבודה השחורה של איסוף הנתונים מכל עמודי התוצאות.

איך מתחילים?

פשוט לחיצה כפולה על הקובץ:

start_ui.bat

זה מפעיל שרת מקומי קטן ופותח את ממשק ההפעלה בדפדפן בכתובת http://127.0.0.1:8765. אפשר גם להפעיל ידנית: 

python nadlan_ui.py

שלבי השימוש

1 פתח דפדפן וחיפוש לחיצה על פתח דפדפן וחיפוש פותחת חלון Edge בעמוד הפתיחה של רשות המיסים.
2 בצע את החיפוש התחבר ומלא את טופס החיפוש באתר עד שטבלת התוצאות מופיעה על המסך.
3 הרץ סריקה חזור לממשק ולחץ הרץ סריקה. הכלי עובר על כל העמודים ומחלץ את כל העסקאות.
4 פתח Excel בסיום לחץ 📂 פתח Excel כדי לפתוח את הקובץ עם התוצאות.

אפשר לעצור באמצע בכל רגע עם הכפתור עצור.

הכפתורים בממשק

כפתורמה הוא עושה
פתח דפדפן וחיפושפותח את Edge בעמוד הפתיחה. לחיצה חוזרת פותחת לשונית חדשה באותה כתובת.
הרץ סריקהמאמת שטבלת התוצאות מוצגת, ואז אוסף את כל העסקאות מכל העמודים.
עצורעוצר את הסריקה הנוכחית.

קובץ הפלט

הקובץ output.xlsx נשמר בתיקיית הפרויקט ומכיל שני גליונות:

  • עסקאות שבוצעו — טבלת תקציר עם 11 עמודות עיקריות (גוש/חלקה, כתובת, תאריך, גודל, קומה, מחיר, מס' חדרים, שנת בנייה ועוד).
  • מורחב — כל העמודות העיקריות בתוספת כל שדות הפירוט המלאים מכל עסקה.

דרישות והתקנה

הכלי משתמש ב‑Python ובשתי ספריות חיצוניות בלבד:

playwright>=1.40
openpyxl>=3.1

התקנה לסביבה (אם צריך להקים מחדש):

py -3.14 -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt

הכלי מפעיל את הדפדפן Microsoft Edge המותקן במחשב (channel="msedge"), כך שאין צורך להוריד דפדפן נוסף.

הערות ופתרון תקלות

  • הכלי משתמש בפרופיל Edge נפרד ב‑%LOCALAPPDATA%\nadlan_scraper\browser-profile — לא בתיקיית OneDrive — כדי למנוע נעילות סנכרון.
  • אם Edge מציג "Opening in existing browser session" — סגור חלונות Edge פתוחים ונסה שוב.
  • אם הסריקה לא מתחילה, ודא שטבלת התוצאות באמת מוצגת בלשונית לפני לחיצה על "הרץ סריקה".
שים לב: תיקיית venv נמצאת בתוך OneDrive ועלולה להיעלם בסנכרון. אם הכלי מפסיק לרוץ, הקם את הסביבה מחדש לפי שלב ההתקנה למעלה.
